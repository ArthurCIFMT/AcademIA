responsável do projeto em 2026-11-03. Ele é fonte de entrada para FND-03, não o
modelo definitivo.

adicionado a este diretório sem substituir ou apagar a imagem original.

para leitura/modelagem sem alterar a imagem ou pedir novamente a fonte.
